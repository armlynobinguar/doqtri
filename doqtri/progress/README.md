# Progress log

Running record of what Doqtri is becoming beyond the v1 `SPEC.md` fast-path.

`SPEC.md` is frozen — it describes v1 as originally scoped. This folder is where
v2+ features are planned, tracked, and marked done. Where a feature here
contradicts a v1 non-goal, the file says so explicitly and supersedes it.

## Convention

- One file per feature: `NNN-kebab-name.md`, numbered in the order work started.
- Every file carries a `Status` line: `Planned` → `In progress` → `Shipped`.
- Update the feature file as work lands — check off steps, record decisions that
  changed mid-build, note anything deferred.
- Add the feature to the index below when the file is created.
